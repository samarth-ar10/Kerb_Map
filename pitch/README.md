# Pitch

- `kerb-map-pitch.html` — the 2-minute pitch (5 slides), one self-contained file: open it in a browser (arrow keys / space to move, F fullscreen, S speaker notes). Slide 3 runs the app's own code on a frozen snapshot of real VastDB responses (map tiles need an internet connection).
- `kerb-map-pitch.pdf` — the same slides as a PDF.
- `kerb-map-demo-30s.mp4` — 30-second product demo: Find parking near College St & McCaul St, Toronto → nearest free kerb spaces → spot card with the evidence frame → "Why we think so". Screens are real captures of the app on the team's VastDB data; the typing and taps are overlays.

Footage: the organisers' supplied Toronto drives (PIE dataset, York University, MIT licence).
